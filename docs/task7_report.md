## Фінальна правка: близькість до порогу і правила про тренди

| Файл | Що зроблено |
|---|---|
| `app/agent/context_builder.py` | під рядком порогів — відстань останніх збережених значень до порогу, напр. `- Disk 89.3 %, 0.7 pp below threshold 90.0 %`; у рядку порогів додано `a threshold is not a safe limit`. Напрямок (above / below / at) визначається за сирими значеннями, як у детекторі (`value > threshold`); різниця менше 0.1 п.п. позначається `<0.1 pp`, щоб 90.04 % не виглядало як «at threshold». Без значення або порогу рядок не виводиться |
| `app/agent/core.py` | промпт: якщо trend analysis недоступний — не стверджувати тренди, піки, сплески, зростання чи стабільність у часі і не прогнозувати; поріг аномалії — не безпечна межа, близькість до порогу називати в п.п., а не оголошувати ситуацію безпечною |
| `tests/test_context_builder.py` | оновлено очікуваний рядок порогів; нові тести: відстань (89.3, 89.96, 90.0, 90.04, 92.04), пропуск невідомих значень, відсутність заголовка без поточних значень |
| `tests/test_agent_core.py` | тест на нові правила промпту |
